Design system

Every token and component the portal is built from, rendered from the same styles.css the pages load — nothing here is a copy or a screenshot. Change a rule and this page changes with the product. Each specimen is labelled with the class you write to get it.

Tokens

The variables on :root. Swatches and sizes are read from the live stylesheet at load, so they cannot drift from the values the product uses.

Colour

Monochrome by constraint: state is carried by weight, border and fill — never by hue.

Type scale

Six levels, a 14px floor, and weight that grows with size (700 only on display and h1).

Feed entry

The activity feed is a list of sentences, not a table. Emphasis falls only on the object of the action and on changed values; the actor's email stays plain.
