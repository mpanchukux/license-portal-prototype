### How "variant-only" was decided

A value is marked **variant-only** when every declaration that produces it sits behind a
selector that only matches while a prototype-settings axis is set away from its default:

| marker in the selector | axis and value |
|---|---|
| `[data-lbg="mesh"]` | Landing > Gradient = 2 (mesh) |
| `[data-lbg="lifted"]` | Landing > Gradient = 3 (lifted) |
| `[data-tableframe="b"]` | Everywhere > Table frame = B (axis retired; attribute pinned to "c") |
| `.mark-warn` | Everywhere > Alert tone = ink |
| `.mark-stop` | Everywhere > Alert tone = ink |
| `.mark-info` | Everywhere > Alert tone = ink |

Declarations found behind each marker: `[data-lbg="mesh"]` 2 · `[data-lbg="lifted"]` 14 · `[data-tableframe="b"]` 0 · `.mark-warn` 3 · `.mark-stop` 0 · `.mark-info` 0. Three of the six match
nothing — they are listed because they are the other values those two axes can take, and a
marker that matches nothing is itself a fact about the axis.

Three near-misses were checked and deliberately **not** marked, because each has a writer that
does not depend on a variant:

- `.tone-black` — the tinted form uses it for one of its three tones (`components.js:3370`), so
  it is not ink-only.
- `.on-ink` — written unconditionally on `#licNewBanner` (`license-details.js:38`).
- `.hc-*` / `#homeCards` — the cards layout is also the phone layout
  (`applyHomeLayout`: `homeLayout() === 'cards' || onPhone()`), so it is reachable with the
  axis on its default.

  style. It is left out of the box-shadow axis because its value is not a shadow.
- `--ic-30` is used twice (`var(--ic-30)`) and is never declared. `--ic-44` appears in the same
  family in the notes; grep finds no declaration for either.
- Four `width`/`height` declarations target a class that sits on an icon but also on something
  else, so they are not counted as icon sizes: `.pc-cta{width:100%}`,
  `.fsheet-apply{width:100%}`, `#homeCards .hc-more .blockmore-go{width:100%}`, and
  `.filterchip .cc-check{width:0}`.

  (`14px/1.45 Ubuntu,…`) carries a size, a line height and a family at once. It is not split,
  so those three values are not in the font-size, line-height or font-family counts.
